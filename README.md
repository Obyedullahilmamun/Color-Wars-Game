# Color Wars

**Color Wars** is a simple and fun 2-player game. Players take turns coloring cells on a grid. The player with the most colored cells wins.

## Features
```
- 2-player turn based game  
- Shows scores in real-time  
- Works on both desktop and mobile  
- Displays winner and allows replay  
```

## Made With
- HTML, CSS, JavaScript
